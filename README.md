# Illinois Research Preprint Templates

Three editable LaTeX styles for an arXiv preprint, all using the Illinois wordmark you provided.

| Template | Best for |
| --- | --- |
| **01 Single Column** | A spacious, report-style paper with a soft blue title card and full-width figures. |
| **02 Polished Double Column** | The same modern title card, with a two-column paper underneath. |
| **03 Minimal Refined** | A quieter, traditional academic look. Choose `main.tex` for a left-aligned title or `main_classic.tex` for a centered one. |

## Open in Overleaf

1. Unzip this bundle on your computer.
2. Go to **Overleaf → New Project → Upload Project** and choose **one** of the three ZIP files inside.
3. Use **pdfLaTeX** and set the main document to `main.tex` (or `main_classic.tex` in the minimal version).
4. Replace the sample title, authors, abstract, figures, and references with your own paper.

All three are unofficial preprint designs, not UIUC-approved publication formats. Please follow Illinois brand rules when using the logo, and switch to the official conference template for anonymous submissions.

**Note:** The ZIP contents and linked source files were checked, but a full LaTeX compile has not been verified here. Review the result in Overleaf before publishing.
